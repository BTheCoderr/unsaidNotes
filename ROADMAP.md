# Unsaid Notes Roadmap

This roadmap describes direction, not guaranteed dates.

## Shipped

- private signed-in reflection flow
- hard-conversation / apology / boundary / unsent-note contexts
- structured AI reflection output
- Supabase Auth + RLS protected storage
- multi-provider AI adapter
- production debug routes disabled by default
- explicit scope boundaries

## Improving

- reflection quality without over-directing the user
- privacy/deletion/export clarity
- provider failure recovery
- mobile and accessibility polish

## Exploring

- optional local-only drafts
- better revisit/history tools
- user-controlled reflection templates
- export formats that keep private data understandable

## Product boundary

The app should help users organize their own thinking. It should not decide what someone must do in a relationship or replace professional support.
