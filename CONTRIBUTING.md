# Contributing to Unsaid Notes

Unsaid Notes is a private reflection journal built with Next.js, TypeScript, Supabase Auth/RLS, and a multi-provider AI layer.

The product is a **reflection buffer**, not therapy, legal advice, crisis support, or an automated relationship decision-maker.

Before a pull request, run the repository's existing validation/build checks and verify privacy boundaries when changing auth, storage, AI prompts, saved reflections, or deletion/export behavior.

A merged commit is not automatic approval for a production deployment.
